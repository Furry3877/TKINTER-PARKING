Problem Statement

Urban Parking Chaos in Indian Cities

Critical bottlenecks faced by conventional parking facilities

⚠️
Chaotic Mixed Parking: Cars, motorbikes, and bicycles packed haphazardly cause dents, scratched paintwork, and traffic gridlocks.
🚲
Damage to Smaller Vehicles: Two-wheelers and bicycles frequently get damaged or trapped when parked beside large SUVs.
🚫
Inefficient Space Utilization: Lack of designated bay demarcations leads to double-parking and wasted capacity.
💸
Unfair Flat Pricing: Charging bikes or bicycles the same flat rate as four-wheelers creates public dissatisfaction.
⏳
Long Queues & Delays: Manual paper ticketing and cash handling create bottleneck congestion at entry and exit gates.
Proposed Solution

Intelligent Vehicle Segregation

Dedicated physical & virtual zones tailored to distinct vehicle classes

🚗 Zone C: Cars & SUVs

• 12 spacious parking bays (C-01 to C-12)

• Wide turning radius and bay clearance

• FASTag / Automated plate check-in

Tariff: ₹40 base + ₹20/hr

🏍️ Zone M: Two-Wheelers

• 16 medium bays (M-01 to M-16)

• Compact scooter and motorcycle stands

• Prevents vehicle jamming

Tariff: ₹20 base + ₹10/hr

🚲 Zone B: Bicycles

• 20 dedicated racks (B-01 to B-20)

• Protects cycles from larger vehicles

• Encourages green urban commuting

Tariff: ₹10 base + ₹5/hr
Pricing & Revenue

Indian Rupee (₹) Tariff & GST Engine

Tiered hourly rates, quick-drop concessions, and automated tax breakdown

⏱️
15-Minute Short Stay Concession: 50% discount on base fee for quick pickups and drops across all categories.
📊
Hourly Formula: Total Fee = Base Fee + ⌈(Minutes − 60) / 60⌉ × Hourly Rate.
🧾
Tax Invoice Simulation: Automated itemized calculation of 18% GST (9% CGST + 9% SGST inclusive) on all exit receipts.
💳
Modern Indian Payment Simulation: Unified support for FASTag RFID, UPI (GPay/PhonePe/Paytm/BHIM), Cash, and RuPay cards.
System Architecture

Model-View-Controller (MVC) Stack

Engineered with Python Standard Library — Zero External pip Dependencies

🏛️
Controller & Logic Layer (parking_system.py): Implements category validation, auto-allocation algorithms, tariff math, and CSV exports.
💾
Database Layer (database.py): SQLite persistence (smart_parking.db) with relational schemas, auto-commit/close connection contexts.
🌐
REST API Server (web_server.py): Multi-threaded HTTP server (ThreadingHTTPServer) delivering JSON endpoints and static assets.
💻
Dual Front-End: Modern Single-Page Application (HTML5/CSS3/Vanilla JS) & Native Desktop Tkinter application.

Evaluation Criteria 2

Code Implementation & Event Handling

Event-driven mechanics ensuring smooth and responsive user interactions

⌨️
Keystroke Input Events (input / <KeyRelease>): Auto-capitalizes license plate input and runs live duplicate parking validation.
🔄
Category Combobox Events (change / <<ComboboxSelected>>): Auto-filters available bays to match chosen category and updates rates.
🖱️
Interactive Bay Click Events: Smart contextual routing (Clicking a Vacant bay opens Check-In; Occupied opens Check-Out & live bill).
🔍
Real-Time Table Search: Instant keystroke search filtering across plate, ticket, driver, and bay without submit button.
⏰
Timer Events: Real-time digital clock (1s interval) and periodic background synchronization (5s interval).
Offline Architecture

100% Offline Execution & PWA

Zero Internet Dependencies — Guaranteed To Work In Any Environment

🚫
Zero External CDNs: Eliminated all Google Fonts in favor of native system font stacks (Segoe UI, -apple-system, Consolas).
📱
Progressive Web App (PWA): Service Worker (service-worker.js) caches all shell resources for offline presentation.
🔌
Mode A (Local Python Server): Operates on localhost:5000 with complete isolation from the public internet.
📂
Mode B (Standalone File Mode): Double-clicking web/index.html (file:///) works 100% offline via client-side localStorage!
📊
Client-Side Blob CSV Export: Dynamically compiles and downloads CSV audit records without a backend server.
API Design

RESTful API Endpoints

Standardized JSON endpoints connecting client interfaces to the data engine

📥
GET /api/stats: Returns real-time occupancy counts, available capacity, and cumulative revenue in INR (₹).
🅿️
GET /api/slots: Returns real-time status, vehicle plate, and elapsed duration for all 48 bays.
💳
GET /api/preview_checkout: Pre-computes stay duration, tariff breakdown, and GST before collecting payment.
📥
POST /api/park: Validates vehicle, assigns bay, stores timestamp, and returns formatted ticket slip.
📤
POST /api/checkout: Collects payment, frees bay, updates ticket to COMPLETED, and issues GST invoice.
⚡
POST /api/demo: Seeds 7 realistic Indian demo vehicles across DL, MH, KA, and HR states.
